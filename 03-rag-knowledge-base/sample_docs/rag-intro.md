# 什么是 RAG？

RAG（Retrieval-Augmented Generation，检索增强生成）是一种将信息检索与大语言模型相结合的技术框架。

## 核心思想

大语言模型虽然知识丰富，但有两个痛点：
1. 知识截止日期问题：模型训练数据是过去的，不知道最新信息
2. 幻觉问题：模型会编造看似合理但实际错误的信息

RAG 的解决思路是：在回答用户问题之前，先从一个外部知识库中检索相关的文档片段，然后把这些片段作为参考资料一起喂给模型，让模型基于真实资料来回答。

## RAG 的基本流程

1. **文档准备阶段（离线）**
   - 收集文档（PDF、Word、网页、Markdown 等）
   - 文档切片（把长文档切成小片段）
   - 向量化（用 Embedding 模型把每个片段转成向量）
   - 存入向量数据库

2. **问答阶段（在线）**
   - 用户提问
   - 把问题也向量化
   - 在向量数据库中做相似度搜索，找到最相关的几个文档片段
   - 把问题 + 检索到的文档片段一起组装成 Prompt
   - 调用 LLM 生成回答

## RAG 的优势

- 知识实时更新：不需要重新训练模型，更新知识库就行
- 减少幻觉：回答基于真实资料，更可靠
- 可解释性强：可以展示答案的来源
- 成本低：比微调便宜得多，也快得多

## 常见优化方向

1. **切片策略优化**：不同大小的切片、语义切片
2. **混合检索**：关键词检索 + 向量检索结合
3. **Rerank 重排序**：用专门的重排模型对初筛结果重新排序
4. **Query 改写**：用 LLM 优化用户的问题再去检索
5. **多模态**：支持图片、视频等非文本内容
